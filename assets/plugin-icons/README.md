# OpenCPN plugin icon family

Canonical visual masters for the shared plugin family. These are project assets, not official OpenCPN, ECDIS, IMO, IEC or IHO symbols.

## Palette

- Deep Navy `#12304A`
- Marine Blue `#2675A9`
- Navigation Cyan `#35A7C8`
- Ice / Off White `#EDF4F7`
- Neutral Grey `#6F7F89`

Red, amber/yellow and green are not generic branding colors because they carry operational semantics in maritime HMIs.

## Geometry

- transparent background; no common badge
- 32 x 32 SVG viewBox
- flat solid colors; no gradients, shadows, gloss or texture
- restrained, consistent radii and visual weight
- one dominant symbol with at most one supporting cue
- optimize actual raster exports for 32 px and verify 16 px legibility

## Masters

- BoatInfo: top-view own vessel plus abstract data marks
- Chart Inspector: buoy/chart object plus focus brackets
- Latitude Ruler: vertical latitude scale plus horizontal reference
- Helm: asymmetric workspace with one main panel, three modules and a navigation cue

Each icon has the full-color master plus white and Deep Navy monochrome variants. Helm remains here as the family master until a dedicated plugin repository exists.
