# Resources

Add only resources the plugin actually needs: scalable toolbar artwork, localized strings, help content, or other package data. Update CMake install rules and inspect the TGZ whenever resources are added.

Icons must remain legible in OpenCPN DAY/DUSK/NIGHT and at supported DPI scales. They are explanatory aids, not substitutes for official chart symbology. Record asset source, author, and license; do not commit private charts or proprietary provider data.
